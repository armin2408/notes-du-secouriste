Résumé : application 100 % hors ligne. Les données saisies restent sur votre téléphone. Aucune transmission vers les serveurs de l’éditeur.

Données traitées (sur l’appareil)

Selon votre utilisation, l’application peut enregistrer localement :

  • identifiants d’intervention (date, statut brouillon ; une clôture pourra être proposée ultérieurement) ;
  • informations victime (nom, prénom, date de naissance, coordonnées, etc.) ;
  • relevés et constantes (mesures, questionnaires, commentaires) ;
  • préférences d’affichage (thème) ;
  • contenu personnalisé de l’aide-mémoire (onglets, textes, images éventuelles).

Stockage dans une base locale (SQLite / Room) et, le cas échéant, dans le stockage privé de l’application. Les données ne quittent pas l’application, sauf si vous ouvrez ou partagez un fichier via une autre application (ex. fiche PDF de l’aide-mémoire dans un lecteur tiers, messagerie). Aucun export PDF d’intervention n’est proposé dans la version actuelle.

Données que nous ne collectons pas

  • pas de compte utilisateur ;
  • pas d’analytics publicitaires intégrés ;
  • pas de synchronisation cloud fournie par l’éditeur ;
  • pas de vente de données personnelles.

Liens externes

L’aide-mémoire peut ouvrir des liens vers des sites tiers (ex. recommandations officielles) dans votre navigateur. Nous ne contrôlons pas le traitement des données par ces services.

Sauvegarde et suppression

  • La sauvegarde Android du téléphone peut inclure les données de l’app selon vos réglages système ; l’application désactive la sauvegarde cloud automatique Android (allowBackup=false).
  • Suppression d’interventions possible dans l’application.
  • La désinstallation supprime en principe toutes les données locales.

Sécurité

Protégez votre appareil (code, biométrie). Évitez de laisser le téléphone accessible sans verrouillage en intervention.

Mineurs

L’application s’adresse aux secouristes formés (PSE), pas aux enfants en usage autonome. Toute donnée concernant un mineur doit être traitée dans le cadre légal et professionnel de votre mission.

Avertissement

Notes du Secouriste ne remplace pas les documents officiels de bilan ni les applications imposées ou recommandées par les institutions et associations de secourisme. Outil d’aide à la prise de notes de terrain uniquement.
