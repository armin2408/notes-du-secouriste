# Politique de confidentialité — Notes du Secouriste

**Dernière mise à jour :** juillet 2026  
**Application :** Notes du Secouriste (`0.3.0-beta`)  
**Éditeur :** [À compléter : nom / association / contact]

## Résumé

Notes du Secouriste est une application **hors ligne**. Les données que vous saisissez (interventions, notes, aide-mémoire personnalisée) sont **stockées uniquement sur votre appareil**. Nous ne collectons pas vos données via l’application et ne les transmettons pas à nos serveurs.

## Données traitées

L’application peut enregistrer localement, selon votre utilisation :

- identifiants d’intervention (date, statut brouillon ; une clôture pourra être proposée dans une version ultérieure) ;
- informations victime que vous saisissez (nom, prénom, date de naissance, coordonnées, etc.) ;
- relevés et constantes (mesures, questionnaires, commentaires) ;
- photos que vous ajoutez à une note d’intervention (stockage local ; métadonnées de localisation retirées à l’import) ;
- préférences d’affichage (thème) ;
- contenu personnalisé de l’aide-mémoire (onglets, textes, images éventuelles) ;
- profil secouriste (identité, contact, compétences) si vous le renseignez.

Ces données sont stockées dans la base locale de l’appareil (SQLite / Room) et, le cas échéant, dans le stockage privé de l’application (fichiers images). Elles ne quittent pas l’application sauf si **vous** choisissez d’ouvrir ou de partager un fichier via une autre application (ex. export PDF d’une synthèse d’intervention, ouverture d’une fiche PDF de l’aide-mémoire, messagerie).

## Données que nous ne collectons pas

- pas de compte utilisateur ;
- pas d’analytics publicitaires intégrés à l’application ;
- pas de synchronisation cloud fournie par l’éditeur ;
- pas de vente de données personnelles.

## Liens externes

L’aide-mémoire peut contenir des liens vers des sites tiers (ex. recommandations officielles). L’ouverture se fait dans votre navigateur ou une autre application ; nous ne contrôlons pas le traitement des données par ces services.

## Sauvegarde et suppression

- La sauvegarde Android de l’appareil peut inclure les données de l’application selon les réglages du téléphone (`allowBackup` est désactivé dans l’application pour limiter les copies automatiques non maîtrisées).
- Vous pouvez supprimer une ou plusieurs interventions depuis l’application.
- La désinstallation de l’application supprime en principe toutes les données locales associées.

## Sécurité

Les données restent sur l’appareil. Protégez votre téléphone (code, biométrie) et évitez de partager l’appareil non verrouillé en intervention.

## Mineurs

L’application s’adresse aux secouristes formés (PSE). Ne saisissez des données concernant des mineurs que dans le cadre légal et professionnel de votre mission.

## Avertissement

Notes du Secouriste **n’est pas** un dispositif médical ni un document officiel de bilan. Elle aide à structurer des **notes de terrain** ; la responsabilité de la transmission et du soin reste celle des professionnels et protocoles en vigueur.
